# Excluded 目录

## 📦 用途
存放**不参与打包的资源**，仅在编辑器开发阶段使用。

## 🎯 适用场景
- 临时测试资源
- 开发阶段的占位资源
- 原始设计稿和参考图
- 不需要发布的辅助资源
- 编辑器工具所需的资源

## 📋 推荐内容
- 测试用的临时资源
- UI 设计稿 PSD/Sketch 源文件
- 资源制作的中间文件
- 开发文档和说明
- 编辑器扩展所需的资源

## ⚠️ 注意事项
- 这些资源**不会被 YooAsset 打包**
- **仅在 Unity 编辑器中可用**
- 不占用应用包体大小
- 运行时无法访问这些资源
- **不会在 YooAsset Collector 中创建 Package**

## 🔧 目录说明
- **Directory**: Assets/EUResources/Excluded
- **用途**: 仅作为本地开发目录
- 建议添加到 `.gitignore`（根据项目需求）
